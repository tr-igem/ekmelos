Lilypond Support
================

Include files
-------------

Include files for [LilyPond](http://lilypond.org/) with tables and functions
that facilitate the use of glyphs from Ekmelos.

### ekmelos-map.ily

Access glyphs by name.

-   ```
    \ekm-glyph GLYPHNAME
    ```
    Draw the glyph GLYPHNAME as markup.
    Calls `\musicglyph` if GLYPHNAME is not defined.

-   ```
    #(ekm-has-glyph? GLYPHNAME)
    ```
    Return `#t` if GLYPHNAME is defined.

-   ```
    #(ekm-glyphname CODEPOINT)
    ```
    Return the glyph name of CODEPOINT, or `#f` if not defined.

### ekmelos-paths.ily

Draw glyphs as paths. This allows e.g. to produce stand-alone SVG output.

-   ```
    \ekm-path CODEPOINT
    ```
    Draw the path of CODEPOINT as markup, or nothing (empty stencil)
    if the path is not defined.

    Used properties:

    -   `font-size` (0)
    -   `thickness` (0)
    -   `filled` (`#t`)

-   ```
    #(ekm-path-stencil CODEPOINT FONTSIZE THICKNESS FILLED)
    ```
    Return a stencil from the path of CODEPOINT, or the empty stencil
    if the path is not defined.

Generate include files
----------------------

The include files are generated by [scripts](../scripts)
for [FontForge](https://fontforge.org/) with the corresponding template file.

-   "glyphnametable.py" with "template-map.ily"
-   "pathtable.py" with "template-paths.ily"

The template files contain the replacement fields:

-   `{0}`: PostScript copyright notice.
-   `{1}`: PostScript font name (fullname).
-   `{2}`: The actual table.

Use and modify them as you wish to generate include files for other fonts.
